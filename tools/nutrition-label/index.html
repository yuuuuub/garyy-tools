🎨 颜色标记指南

🟢 绿色 — 多多益善

  • 膳食纤维 — 促进消化健康
  • 蛋白质 — 构建肌肉组织
  • 维生素 A、C、D
  • 钙、铁、钾
  • 选择这些含量高的食品

🟡 黄色 — 适量摄入

  • 总脂肪 — 需要但不过量
  • 碳水化合物 — 主要能量来源
  • 胆固醇 — 每天 < 300mg
  • 关注份量和每日摄入

🔴 红色 — 尽量限制

  • 饱和脂肪 — 增加心血管风险
  • 反式脂肪 — 尽量避免
  • 钠 — 每天 < 2000mg
  • 添加糖 — 每天 < 25-50g

快速判断法则：
• ≤5% DV = 该营养素含量低
• 10%-19% DV = 该营养素含量中等
• ≥20% DV = 该营养素含量高
* 此判断适用于需要限制的营养素（脂肪、钠、糖）。对于纤维、维生素等，高%DV 反而是好事。

世界卫生组织 (WHO) 建议：
• 成人每日添加糖摄入量不超过 50g（约12.5块方糖）
• 理想情况下不超过 25g（约6块方糖）
• 一瓶可乐（39g糖）已占每日建议上限的 78%

💡 阅读营养标签小贴士

Tip 1

先看份量：很多包装食品标注的是"每份"而非整包含量。一包薯片可能含有 2-3 份，实际摄入加倍。

Tip 2

关注前三项：配料表按含量从高到低排列。如果糖、油排在前三位，说明该产品不太健康。

Tip 3

0 ≠ 没有：标注"0g 反式脂肪"可能仍有 <0.5g/份。留意配料表中的"氢化植物油"。

Tip 4

钠不容忽视：加工食品是钠的主要来源。每天摄入超过 2000mg 会增加高血压风险。

Tip 5

全谷物是关键：配料表中"全麦"、"全谷物"排在第一位才是真正的全谷物食品。

Tip 6

糖的"马甲"：果葡糖浆、浓缩果汁、蜂蜜、麦芽糖都属于添加糖，只是名字不同。

Tip 7

比较同类产品：同是面包，不同品牌的钠含量可能相差 3 倍。学会对比选择。

Tip 8

警惕"健康光环"："低脂"可能高糖，"无糖"可能高脂。查看完整营养表才可靠。
