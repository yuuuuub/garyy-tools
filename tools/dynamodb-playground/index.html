语法参考

数据类型

S - String 字符串
N - Number 数值
B - Binary 二进制
SS/NS/BS - String/Number/Binary Set
L - List 列表
M - Map 映射
BOOL - Boolean 布尔值
NULL - 空值

表达式语法

KeyConditionExpression - 主键条件
FilterExpression - 过滤表达式
ProjectionExpression - 字段投影
ConditionExpression - 写入条件
UpdateExpression - 更新表达式

设计模式参考

单表设计

PK: USER#userId SK: PROFILE 用户资料
PK: USER#userId SK: ORDER#orderId 用户订单
PK: ORDER#orderId SK: ITEM#itemId 订单商品

GSI 模式

GSI1PK: status | GSI1SK: createdAt - 按状态查询
GSI2PK: email - 按邮箱查找用户
GSI3PK: category | GSI3SK: price - 按类别和价格
