Waste Sorting Guide — 中国生活垃圾分类指南

🔵 可回收物 Recyclable

适宜回收利用和资源化利用的生活废弃物。投放时应保持清洁干燥，避免污染。

📦 纸类、塑料瓶、金属罐、玻璃瓶、旧衣物、电子产品

🔴 有害垃圾 Hazardous

对人体健康或自然环境造成直接或潜在危害的废弃物。需单独投放，由专业机构处理。

💊 废电池、废灯管、废药品、废油漆、杀虫剂

🟢 湿垃圾/厨余垃圾 Kitchen

易腐的生物质生活废弃物。应从产生时与其他垃圾分开，投放前沥干水分。

🍎 剩饭剩菜、瓜皮果核、花卉绿植、过期食品

⚫ 干垃圾/其他垃圾 Residual

除可回收物、有害垃圾、湿垃圾以外的其他生活废弃物。尽量沥干水分后投放。

🧻 餐巾纸、污损塑料袋、陶瓷碎片、一次性餐具、烟蒂
