Redis 命令速查手册

常用Redis数据结构操作命令中文参考
StringHashListSetZSet键管理服务器发布订阅事务脚本

String 字符串

StringSET key value SET key value EX 60 SET key value PX 60000 SET key value NX SET key value XX
设置键值（EX=秒，PX=毫秒，NX=仅不存在，XX=仅存在）
StringGET key MGET key1 key2 key3
获取值 / 批量获取
StringINCR key INCRBY key 10 DECR key DECRBY key 5
原子递增/递减
StringAPPEND key " world" STRLEN key
追加字符串 / 获取长度
StringSETNX key value SETEX key 3600 value
不存在时设置 / 设置并设置过期
StringSETRANGE key 6 "Redis" GETRANGE key 0 4
部分替换 / 子串获取
StringMSET k1 v1 k2 v2 k3 v3 MSETNX k1 v1 k2 v2
批量设置 / 不存在时批量设置

Hash 哈希表

HashHSET user:1 name "张三" age 25 HMSET user:1 name "张三" age 25 email "test@ex.com"
设置哈希字段
HashHGET user:1 name HMGET user:1 name age HGETALL user:1
获取哈希字段 / 获取所有字段和值
HashHDEL user:1 email HEXISTS user:1 name
删除字段 / 检查字段是否存在
HashHINCRBY user:1 age 1 HINCRBYFLOAT user:1 score 0.5
哈希字段原子递增
HashHKEYS user:1 HVALS user:1 HLEN user:1
获取所有字段名/值/字段数量
HashHSCAN user:1 0 MATCH name* COUNT 10
增量迭代哈希字段

List 列表

ListLPUSH mylist a b c RPUSH mylist x y z
左端/右端插入
ListLPOP mylist RPOP mylist LPOP mylist 3
左端/右端弹出（可指定数量）
ListLRANGE mylist 0 -1 LRANGE mylist 0 9
获取列表范围（0到末尾 / 前10个）
ListLLEN mylist LINDEX mylist 2
列表长度 / 按索引获取元素
ListLINSERT mylist BEFORE b "before-b" LINSERT mylist AFTER b "after-b"
在指定元素前/后插入
ListLREM mylist 2 "a" LTRIM mylist 0 99
删除指定值（2个） / 裁剪列表
ListBRPOP mylist 30 BLPOP mylist 0
阻塞式弹出（30秒超时 / 永久阻塞）
ListLMOVE source dest LEFT RIGHT LPOS mylist "a"
元素移动 / 查找元素位置

Set 集合

SetSADD myset a b c d SADD myset a # 重复元素被忽略
添加集合元素
SetSMEMBERS myset SCARD myset
获取所有元素 / 集合大小
SetSISMEMBER myset a SRANDMEMBER myset 2
判断是否存在 / 随机获取元素
SetSREM myset a b SPOP myset
删除元素 / 随机弹出
SetSINTER set1 set2 SUNION set1 set2 SDIFF set1 set2
交集 / 并集 / 差集
SetSMOVE src dest "member" SSCAN myset 0 MATCH pattern* COUNT 100
移动元素 / 增量迭代

ZSet 有序集合

ZSetZADD leaderboard 100 "player1" 85 "player2" 95 "player3"
添加带分数的元素
ZSetZRANGE leaderboard 0 -1 WITHSCORES ZREVRANGE leaderboard 0 9 WITHSCORES
按分数升序/降序获取范围
ZSetZRANGEBYSCORE leaderboard 80 100 ZRANGEBYSCORE leaderboard -inf +inf LIMIT 0 10
按分数范围查询（带分页）
ZSetZSCORE leaderboard "player1" ZRANK leaderboard "player1" ZREVRANK leaderboard "player1"
获取分数 / 排名（升序/降序）
ZSetZINCRBY leaderboard 5 "player1" ZCARD leaderboard
分数增加 / 集合大小
ZSetZREM leaderboard "player1" ZREMRANGEBYRANK leaderboard 0 2 ZREMRANGEBYSCORE leaderboard 0 50
删除元素 / 按排名/分数范围删除
ZSetZUNIONSTORE dest 2 zset1 zset2 AGGREGATE SUM
有序集合并集存储

键管理

服务器KEYS user:* KEYS order:??:*
查找匹配的键（生产慎用）
服务器SCAN 0 MATCH user:* COUNT 100
增量迭代查找键（推荐替代KEYS）
服务器EXISTS key TYPE key TTL key PTTL key
检查键是否存在 / 类型 / 剩余秒/毫秒
服务器EXPIRE key 3600 PEXPIRE key 3600000 PERSIST key
设置过期时间 / 取消过期
服务器RENAME oldkey newkey RENAMENX oldkey newkey
重命名键 / 不存在时重命名
服务器DEL key1 key2 key3 UNLINK key1 key2
删除键（UNLINK异步删除大key）
服务器OBJECT ENCODING key OBJECT IDLETIME key OBJECT REFCOUNT key
查看键的编码/空闲时间/引用计数
服务器DUMP key RESTORE key 0 "\x00\x05..." REPLACE
序列化/反序列化键值

服务器管理

服务器INFO INFO memory INFO keyspace INFO clients
查看服务器信息
服务器DBSIZE RANDOMKEY SELECT 0
键总数 / 随机键 / 切换数据库
服务器FLUSHDB FLUSHALL
⚠️ 清空当前DB / 所有DB
服务器CONFIG GET maxmemory CONFIG SET maxmemory 1gb CONFIG REWRITE
获取/设置配置
服务器CLIENT LIST CLIENT KILL addr ip:port CLIENT SETNAME myconn
客户端管理
服务器SLOWLOG GET 10 SLOWLOG LEN SLOWLOG RESET
慢查询日志

发布订阅

服务器PUBLISH channel "message"
发布消息到频道
服务器SUBSCRIBE channel1 channel2 UNSUBSCRIBE channel1
订阅/取消订阅频道
服务器PSUBSCRIBE news.* PUNSUBSCRIBE news.*
模式订阅（通配符）
服务器PUBSUB CHANNELS PUBSUB NUMSUB channel1 PUBSUB NUMPAT
查看活跃频道/订阅数/模式数

事务

服务器MULTI SET key1 "val1" SET key2 "val2" EXEC
开启事务并执行
服务器MULTI SET key1 "val1" DISCARD
放弃事务中的所有命令
服务器WATCH key MULTI SET key "newval" EXEC # 如果key被其他客户端修改，EXEC返回nil
乐观锁（CAS）

Lua 脚本

服务器EVAL "return redis.call('GET', KEYS[1])" 1 mykey EVAL "return {redis.call('GET', KEYS[1]), redis.call('GET', KEYS[2])}" 2 k1 k2
执行Lua脚本
服务器SCRIPT LOAD "return 1" EVALSHA sha1 0 SCRIPT EXISTS sha1 SCRIPT FLUSH
脚本缓存管理
