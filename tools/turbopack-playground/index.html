说明

开发速度

Webpack (1000 模块)：
冷启动: ~30s
HMR: ~500ms

Turbopack (1000 模块)：
冷启动: ~1.8s
HMR: ~50ms

结论：Turbopack 快 10x+

配置复杂度

Webpack:
• 需要 webpack.config.js
• 大量 loader/plugin 配置
• 需手动配置模块解析

Turbopack:
• 零配置启动
• 自动识别文件类型
• 内置最优默认值
• 仅需 next.config.js

缓存策略

Webpack:
• cache: { type: 'filesystem' }
• 需要手动配置
• 本地缓存

Turbopack:
• 自动增量缓存
• 远程缓存（Vercel）
• 基于文件内容哈希

生态兼容性

Webpack:
• 最完整的插件生态
• 几乎所有框架支持
• 成熟稳定

Turbopack:
• 目前仅 Next.js 集成
• 正在扩展框架支持
• 快速发展中

Next.js 14+ 启用

// next.config.js
module.exports = {
  turbo: {
    loaders: {
      '.svg': ['@svgr/webpack'],
    },
    rules: {
      '*.md': {
        loaders: ['raw-loader'],
        as: '*.js',
      },
    },
  },
};

Monorepo 配置

{
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": [".next/**", "dist/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    },
    "lint": { "outputs": [] },
    "test": {
      "dependsOn": ["build"]
    }
  }
}

远程缓存

# 启用 Vercel 远程缓存
npx turbo login
npx turbo link

# 团队共享缓存
# CI 中设置：
VERCEL_TOKEN=xxx turbo run build

Turbopack API

// 程序化使用 Turbopack
import { createServer } from 'turbo';

const server = createServer({
  dir: process.cwd(),
  port: 3000,
  hot: true,
});

server.listen();
