三原色 (Primary Colors)

三原色是色彩的基本组成，无法通过其他颜色混合得到。在传统色彩理论（RYB）中为红黄蓝，在光的色彩模型（RGB）中为红绿蓝。

间色 (Secondary Colors)

复色 (Tertiary Colors)

复色由一个原色和一个相邻间色混合而成，形成色轮上的12色系统。

点击色轮取色

色轮位置说明

色轮按0°-360°排列色相：0°红 → 60°黄 → 120°绿 → 180°青 → 240°蓝 → 300°品红 → 360°红

暖色 Warm Colors

红、橙、黄色系。给人温暖、热情、活力的感觉。常用于餐饮、娱乐行业。

冷色 Cool Colors

蓝、绿、紫色系。给人冷静、专业、信任的感觉。常用于科技、医疗行业。
