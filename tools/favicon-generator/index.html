方法一：标准方式（推荐）

将下载的文件放入网站根目录，然后在 HTML <head> 中添加： 

<link rel="icon" type="image/x-icon" href="/favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="64x64" href="/favicon-64x64.png">
<link rel="apple-touch-icon" sizes="128x128" href="/favicon-128x128.png">

方法二：使用 Base64 Data URI

不需要额外文件，直接在 HTML 中内联图标： 

<link rel="icon" href="data:image/png;base64,...">

常见问题

  • favicon.ico 是什么格式？ 本工具生成的实际为 PNG 格式，为兼容性文件名保存为 .ico。现代浏览器都能识别 PNG 格式的 favicon。
  • 为什么我的 favicon 不显示？ 检查文件路径是否正确，以及浏览器是否缓存了旧图标。可以尝试在链接后加 ?v=2 来强制刷新缓存。
  • 推荐哪个尺寸？ 建议至少准备 32x32 和 64x64 两个尺寸，以满足不同设备和场景需求。
  • 支持透明背景吗？ 本工具暂不支持透明背景，所有图标均为纯色或渐变背景。
