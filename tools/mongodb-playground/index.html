CRUD 模板

📄 查询文档

db.collection.find(query, projection)

📄 查询单个

db.collection.findOne(query)

➕ 插入文档

db.collection.insertOne(document)

✏️ 更新文档

db.collection.updateOne(filter, update)

🗑️ 删除文档

db.collection.deleteOne(filter)

📊 聚合管道

db.collection.aggregate([...stages])

聚合管道模板

$group: { _id: "$status", count: { $sum: 1 } } 按字段分组统计
$match: { age: { $gte: 18 } } 过滤文档
$sort: { created_at: -1 } 排序
$project: { name: 1, email: 1, _id: 0 } 字段投影
$unwind: "$tags" 展开数组字段
$lookup: { from: "orders", localField: "_id", foreignField: "userId", as: "orders" } 关联查询

语法参考

查询操作符

$eq $ne $gt $gte $lt $lte比较操作符
$in $nin包含/不包含
$and $or $not逻辑操作符
$regex正则匹配

更新操作符

$set $unset设置/删除字段
$inc $mul递增/递减
$push $pull $addToSet数组操作
