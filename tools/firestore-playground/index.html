Firestore 概念参考

数据模型

Collection - 文档集合，类似表
Document - 文档，类似行，最大1MB
Subcollection - 子集合，嵌套在文档下
Reference - 文档引用，支持跨集合

查询操作符

==, !=, <, <=, >, >= 比较
in, array-contains 包含
orderBy, limit 排序限制
startAt, endAt 分页游标
