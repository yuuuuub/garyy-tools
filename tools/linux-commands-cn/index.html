文件操作

文件ls -lah
列出文件（含隐藏、详细、人类可读大小）
文件touch file.txt
创建空文件或更新时间戳
文件cp -r source/ dest/
复制文件或目录（-r递归）
文件mv old.txt new.txt
移动/重命名文件
文件rm -rf dir/
⚠️ 递归强制删除（不可恢复）
文件cat file.txt
查看文件内容
文件head -n 20 file.txt
查看文件前20行
文件tail -f /var/log/syslog
实时跟踪文件末尾更新
文件less file.txt
分页查看文件（q退出）
文件wc -l file.txt
统计文件行数
文件file myfile
查看文件类型
文件stat file.txt
查看文件详细信息（大小、时间、权限）
文件ln -s /path/to/target link_name
创建软链接
磁盘du -sh /var/log
查看目录大小
文件find / -type f -size +100M
查找大于100M的文件

目录操作

文件mkdir -p dir/subdir
递归创建目录
文件rmdir -p dir/subdir
递归删除空目录
文件cd -
切换到上一个目录
文件pwd
显示当前工作目录
文件tree -L 2 -I node_modules
树形显示目录（2层，排除node_modules）
文件find /var -type d -name "*.log"
查找指定名称的目录

文本处理

文本grep -rn "error" /var/log/
递归搜索文件内容（含行号）
文本grep -E "error|warning" log.txt
正则表达式搜索（多模式）
文本grep -v "^#" config.conf
过滤掉注释行
文本grep -i "error" log.txt
忽略大小写搜索
文本awk '{print $1, $3}' file.txt
提取第1列和第3列
文本awk '$3 > 100' data.txt
筛选第3列大于100的行
文本sed 's/old/new/g' file.txt
替换文本（全局）
文本sed -i 's/foo/bar/g' file.txt
直接修改文件内容
文本sed -i '/^#/d' config.conf
删除所有注释行
文本cut -d':' -f1,3 /etc/passwd
按分隔符提取列
文本sort -t',' -k2 -n data.csv
按第2列数值排序
文本sort file.txt | uniq -c
统计重复行并计数
文本echo "Hello" | tr 'a-z' 'A-Z'
字符替换/删除/压缩
文本find . -name "*.tmp" | xargs rm
将标准输入转为命令参数
文本mount | column -t
格式化输出为表格

搜索与查找

文件find /var/log -name "*.log" -mtime -7
查找7天内修改过的log文件
文件find . -name "*.bak" -exec rm {} \;
查找并执行操作
系统which python3
查找命令所在路径
系统whereis nginx
查找命令、源码和手册位置
文件locate filename
快速搜索文件（基于索引，需updatedb）
系统type ls
查看命令类型（别名/内建/外部）

权限管理

权限chmod 755 script.sh
设置文件权限（rwxr-xr-x）
权限chmod +x script.sh
添加可执行权限
权限chmod -R 755 /var/www
递归修改目录权限
权限chown user:group file.txt
修改文件所有者和组
权限chown -R www-data:www-data /var/www
递归修改目录所有者
权限sudo command
权限passwd username
修改用户密码
权限visudo
安全编辑sudoers文件

用户管理

权限useradd -m -s /bin/bash newuser
创建用户（带家目录和Shell）
权限usermod -aG docker username
将用户添加到附加组
权限userdel -r username
删除用户及家目录
权限groupadd groupname
创建用户组
权限id username
查看用户UID、GID和所属组
权限whoami
显示当前用户名
权限last -10
查看最近10次登录记录

进程管理

系统ps aux | grep nginx
查看所有进程并过滤
系统ps -ef | grep node
查看进程树
系统top -bn1 | head -20
查看系统资源使用概览
系统htop
交互式进程查看器（需安装）
系统kill -9 PID
强制终止进程
系统killall nginx
按名称终止所有进程
系统pkill -f "python app.py"
按命令模式匹配终止进程
系统nohup ./script.sh &
后台运行，关闭终端不停止
系统jobs -l
查看后台任务
系统fg %1
将后台任务调到前台
系统bg %1
在后台继续运行暂停的任务
系统lsof -i :80
查看占用指定端口的进程
系统nice -n 10 ./heavy-task.sh
以低优先级运行命令
系统pgrep -a nginx
按名称查找进程PID

网络ss -tlnp

压缩与解压

文件tar -czf archive.tar.gz dir/
打包并gzip压缩
文件tar -xzf archive.tar.gz
解压gzip压缩包
文件tar -cjf archive.tar.bz2 dir/
打包并bzip2压缩
文件tar -xjf archive.tar.bz2
解压bzip2压缩包
文件zip -r archive.zip dir/
创建zip压缩包
文件unzip archive.zip -d target/
解压到指定目录
文件gzip -k file.txt
压缩文件（保留原文件）
文件gunzip file.txt.gz
解压gzip文件

定时任务

系统crontab -e
编辑当前用户的定时任务
系统crontab -l
列出当前用户的定时任务
系统0 2 * * * /path/to/script.sh
每天凌晨2点执行
系统0 * * * * /path/to/script.sh
每小时整点执行
系统0 0 * * 0 /path/to/weekly.sh
每周日午夜执行
系统echo "command" | at now + 30 minutes
30分钟后执行一次命令
