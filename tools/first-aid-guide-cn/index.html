🩺 急救指南

常见急症处理方法大全 | 关键时刻能救命

🫀 心脏骤停 / CPR 心肺复苏

应该做什么：

  1. 确认环境安全，轻拍双肩、大声呼唤判断反应。
  2. 无反应→拨打120，打开免提，让人取AED。
  3. 观察胸部起伏5-10秒判断呼吸（濒死喘息不算正常呼吸）。
  4. 无正常呼吸→立即胸外按压：掌根放胸骨中下段（两乳头连线中点），双臂伸直垂直下压5-6cm，频率100-120次/分钟。
  5. 每30次按压→2次人工呼吸（如受过训练）。只按压也有效。
  6. AED到达后立即使用，按语音提示操作。持续CPR直到急救人员到达。

不要做什么：

  • 不要浪费时间检查脉搏。
  • 不要因担心按断肋骨而不敢用力——用力才能救命。
  • 不要频繁中断按压（不超过10秒）。
  • 不要在伤者口中塞任何东西。
一旦确认无反应且无正常呼吸，立即拨打120并开始胸外按压。

🩸 出血 / 止血

应该做什么：

  1. 戴手套（如有），避免直接接触血液。
  2. 用干净纱布/衣物直接按压伤口，持续用力。
  3. 纱布浸透不要更换，在上面再加一层继续按压。
  4. 抬高受伤部位至心脏以上，帮助减缓出血。
  5. 四肢大出血且按压无效时，可在伤口近心端使用止血带（距伤口5-8cm），记录使用时间。

不要做什么：

  • 不要移除嵌在伤口中的异物——固定包扎。
  • 不要用止血带超过2小时不松开。
  • 不要用脏手接触伤口。
  • 不要给伤者进食或喝水——可能需手术。
出血无法控制、伤口很深、出现休克迹象（苍白、冷汗）时立即拨打120。

🦴 骨折 / 扭伤

应该做什么：

  1. 疑似脊柱/颈部损伤→不要移动伤者！保持头颈躯干一条直线，呼叫120。
  2. 四肢骨折：用夹板固定骨折处上下两个关节。夹板可用木板、杂志、卷起的衣物替代。
  3. 绷带固定夹板，不要系在骨折处。固定后检查远端血液循环。
  4. 扭伤遵循RICE原则：Rest休息、Ice冰敷(20分钟/次)、Compress加压包扎、Elevate抬高患肢。
  5. 开放性骨折（骨头外露）用无菌纱布覆盖，不要试图把骨头推回。

不要做什么：

  • 不要试图复位或对齐断裂的骨头。
  • 不要移动疑似脊柱损伤的伤者。
  • 扭伤48小时内不要热敷、不要按摩。
  • 不要给伤者进食或水——可能需急诊手术。
疑似脊柱/头部/骨盆骨折、开放性骨折、肢体变形严重或麻木发紫时立即拨打120。

🔥 烧伤 / 烫伤

应该做什么：

  1. 立即远离热源或化学物质。电击伤先切断电源。
  2. 用流动凉水（非冰水）冲洗烧伤部位至少20分钟，水温15-25°C为宜。
  3. 轻轻去除衣物首饰，粘在皮肤上的不要撕扯。
  4. 用干净干燥的纱布轻轻覆盖，避免摩擦。
  5. 化学烧伤：大量流动水冲洗至少20分钟。

不要做什么：

  • 不要用冰块敷——会加重组织损伤。
  • 不要涂抹牙膏、酱油、醋等偏方——增加感染风险。
  • 不要戳破水泡——水泡保护创面。
  • 不要用黏性材料直接覆盖烧伤区域。
  • 不要给大面积烧伤者大量喝水——可能导致电解质紊乱。
烧伤面积大于手掌、深度烧伤、面部/手部/关节烧伤、呼吸困难时拨打120。

🥵 中暑 / 热射病

应该做什么：

  1. 立即转移到阴凉通风处或空调房间。
  2. 脱去多余衣物，松开紧身衣。
  3. 凉毛巾敷颈部、腋窝、腹股沟等大血管处，扇风增加散热。
  4. 清醒者小口慢饮凉盐水（1L水+半勺盐）或运动饮料。
  5. 持续监测体温，目标降至38°C左右。

不要做什么：

  • 不要给意识不清者喂水——可能导致误吸。
  • 不要用冰水直接浸泡——可能阻碍散热。
  • 不要给中暑者服用退烧药——对中暑无效且可能伤肝。
体温超过40°C、意识模糊、皮肤干热不出汗（热射病）、抽搐时立即拨打120。

🫁 窒息 / 异物卡喉

应该做什么：

  1. 能咳嗽说话→鼓励继续用力咳嗽。
  2. 无法咳嗽说话（双手抓喉咙）→立即实施海姆立克法：站在背后，双臂环绕腰部，一手握拳放在脐上方，另一手抓拳快速向内向上冲击腹部。
  3. 重复冲击直到异物排出或伤者失去意识。
  4. 失去意识→平放→立即CPR。
  5. 1岁以下婴儿：面朝下拍背5次→翻转两指按压胸部5次，交替进行。

不要做什么：

  • 能咳嗽说话时不要做海姆立克法。
  • 不要用手盲目掏取异物。
  • 不要喂水或食物试图冲下去。
伤者失去意识或海姆立克法无效，立即拨打120。

☠️ 中毒

应该做什么：

  1. 移离中毒环境（一氧化碳中毒移至通风处）。
  2. 尽量确定中毒物质、剂量、时间，收集毒物容器给急救人员。
  3. 毒物接触皮肤/眼睛→大量流动水冲洗15-20分钟。
  4. 吸入有毒气体→转移至空气新鲜处，解开紧身衣物。
  5. 蛇咬→保持静止，伤肢低于心脏，固定。记录咬伤时间和蛇的特征。

不要做什么：

  • 不要自行催吐——某些毒物催吐会造成二次伤害。
  • 不要给伤者食物或饮料（除非毒物控制中心指示）。
  • 不要用嘴吸蛇毒。
  • 不要用"解毒偏方"。
任何中毒情况都应立即拨打120，同时收集毒物样本给急救人员。

💉 严重过敏反应 / 过敏性休克

应该做什么：

  1. 识别迹象：皮肤红疹/荨麻疹、面部/嘴唇肿胀、呼吸困难、喉咙发紧、头晕。
  2. 立即拨打120——过敏性休克可能数分钟内致命。
  3. 有EpiPen（肾上腺素笔）→大腿外侧中部注射，按住3秒。可隔着衣物注射。
  4. 平躺抬高双腿（呼吸困难则半坐位）。
  5. 蜂蜇用卡片刮除毒刺，不要用镊子。

不要做什么：

  • 不要等待观察——过敏性休克进展极快。
  • 不要给呼吸困难者喂口服药。
  • 不要让伤者站立或走动。
过敏性休克必须立即拨打120，不要自己驾车送医。

🌊 溺水

应该做什么：

  1. 确保自身安全，使用长杆、绳子、救生圈施救。从背后接近溺水者。
  2. 救上岸后检查反应和呼吸。
  3. 无反应且无正常呼吸→先做5次人工呼吸（缺氧），然后30:2交替。
  4. 使用AED（擦干胸部再贴电极片）。
  5. 保持体温——用毛毯覆盖防止体温过低。

不要做什么：

  • 不要独自下水救人——呼叫求助并拨打120。
  • 不要浪费时间"控水"（倒挂排水）——延迟CPR且增加误吸风险。
  • 不要停止CPR直到急救人员到达。
任何溺水事件都应拨打120，即使伤者看似已恢复（可能发生二次淹溺）。
